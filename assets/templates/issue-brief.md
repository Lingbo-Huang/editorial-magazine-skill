# Issue brief 模板

本文件是可复用工作表。复制到具体刊物目录填写；发布成稿时删除说明性括号，不将空白字段当成正文。

## 编辑命题

- 刊名/品牌：
- 本期标题与中心问题：
- 目标读者、已有知识与阅读场景：
- 读完后形成的理解或可以完成的行动：
- 内容方式：原文排版 / 精选编刊 / 原创专题。
- 内容来源、保留范围、可删改范围：
- 作者/贡献者信息及公开范围：
- 屏幕 / PDF / 分享卡片等实际交付物：

## 艺术指导

- 一句视觉命题：
- 三个视觉词及分别对应的具体设计：
- 一个主要的视觉对照关系：
- 签名元素及在封面、正文、收尾的用法：
- 不采用的本期视觉表达：
- 颜色角色与 token：
- 中文/拉丁字体、回退与授权：
- 字号、行高、行长、版心、基线和中缝：
- 首个代表性样张：封面 / 正文跨页 / 动态场景。

## 页面与素材

- 页面地图文件：
- 每个跨页的编辑任务与阅读顺序：
- 资产清单：id、用途、来源/使用范围、尺寸、裁切焦点、alt、可编辑源。
- 动态场景：表达目的、图层、锚点、幅度、周期、相位、静帧、停止条件。
- 没有素材或证据的部分如何处理：

## 验收

- 真实设备/视口与放大比例：
- 艺术审校修改记录：
- 内容完整性、图表/代码事实核对：
- 纸面点击保护、纸叶翻转、离屏、后台、减少动态、无脚本：
- PDF 是否实际导出并逐页检查：
- 访问权限与发布范围：
- 已实际通过 / 代码检查 / 未验 / 失败项：
