# 阅读器、响应式与派生输出

## 1. 内容模型先于翻页效果

用稳定的 issue、article、page/scene id 连接内容。文章包含标题、作者、内容、来源与媒体；页面地图决定其呈现位置。目录、页码和深链接从同一模型生成。跨页配对是视图，不能为了左右配对复制或删改正文。

短刊可使用静态 HTML 与独立 CSS/JS；长刊复用项目组件。优先原生功能，不为书页效果默认增加框架。生产接入需处理资源销毁、错误和权限，不能直接把独立 demo 粘进 SSR 顶层执行。

## 2. 自动适配的纸书视图

默认大屏双页、小屏单页，不提供连续阅读或阅读模式切换控件。双页中的每页仍有舒适行宽；小屏重新排版，不整体缩小。无脚本降级可按 DOM 顺序展示静态全文，这是后备输出，不是另一个工具栏模式。

页面使用稳定 id，目录和 URL 定位文章。响应式断点按可用行宽选择；跨断点时保留当前文章，不因配对左右页重复或丢失正文。页高以阅读为准，不能用 overflow:hidden 掩盖溢出；长内容增加续页或自然增长。

将“选中的页面”与“当前跨页的左页”分开：前者是导航状态，后者是布局派生值。目录点到右页后再缩窄窗口，必须仍看到右页。响应式切换不追加浏览历史；返回最初无锚点地址恢复封面。

## 3. 翻页与导航

封面整页点击打开；桌面左页点击后退、右页点击前进，小屏根据左右区域翻页。纸张两侧保留细箭头，首尾不可越界，不循环。短点击、文本拖选、链接点击和垂直滚动分别处理，详见 [纸书交互](book-interaction.md)。目录链接保留原生 href 和地址状态；刷新、复制链接、浏览器返回能够定位内容。链接到失效页时给出可理解回退。

左右箭头仅在阅读上下文生效；输入、编辑、弹层、交互图中不拦截。使用触摸滑动时保留按钮替代，并区分垂直滚动、文字选择与水平翻页。不要锁定浏览器缩放。

长页翻到下一页后，将焦点移到新页合适位置，滚动回页首；目录跳转则定位目标。切页期间不能把所有内容设为不可见并长时间等待动画结束。

## 4. 封面和书本效果

封面倾角、边层、翻开动画都是渐进增强。先显示能读的封面，再增强效果；减少动态模式直接切换。翻页中间态不出现镜像正文、穿帮页面和透明重影。

桌面封面同时受可用宽度和高度约束，独立调整标题、字级和间距下限，让普通笔记本首屏也能看到完整主视觉。正文不随封面一起缩小。封面与内页尺寸不同，翻页副本按各自真实排版尺寸衔接； resize 应清除旧尺寸副本。

BaiLian 使用双面纸叶绕书脊旋转，不能只把整本书缩放或横移当成翻页。正反面文字不镜像，翻页阴影随纸面角度变化。无法处理动态文字重排的翻页库，不适合作为手机长文阅读的唯一入口。

## 5. 工具栏与目录可达性

只保留安静的目录入口；不出现动态暂停、连续阅读、主题切换和封面进入按钮。两侧箭头跟随纸张区域，长页仍可找到。采用 sticky 时，锚点滚动和键盘焦点必须避开工具栏；工具栏换行导致高度变化时同步计算安全间距。

原生 dialog 支持关闭、Esc、焦点恢复和滚动内容。取消目录时回到触发按钮；选中文章时焦点进入目标页，不能被稍后触发的 close 事件抢回工具栏。每次打开重置上次的返回值，避免 Esc 意外重复上次导航。隐藏页使用真正的 hidden/inert，避免 Tab 到看不见的链接。按钮有明确文字或可访问名称，触摸目标至少 44px。

页码状态用适度的 aria-live 更新，不对每一帧动画播报。图形装饰 aria-hidden，必要图像提供有意义描述；Canvas 旁有等价说明，不能只剩“你的浏览器不支持 Canvas”。

## 6. 媒体与性能

首屏优先文本和当前主视觉，后续图像逐步加载。媒体保留宽高比，避免版面跳动。当前页/邻页之外的大图和视频减少解码与预加载；长刊测试内存增长和反复翻页后的回收。

动画使用统一生命周期，见动态规范。无脚本时显示连续正文、图注和静帧，隐藏不可用的工具控件。Canvas 失败不影响其他内容；字体加载失败使用相容回退。

真实素材载入后检查排版，而不是用占位矩形通过验收。离线文件如需要外部字体/脚本，明确说明；便携交付优先本地资产与系统字体。HTML 与 CSS/JS 更新时使用同一资源版本参数，核对实际加载版本，避免浏览器旧缓存造成看似未修复。

## 7. 小屏重新编排的细则

- 跨页大图变成完整独立图，或提供放大入口；不留下被书缝切成两半的图。
- 竖排装饰改横排或隐藏，正文标题始终保留。
- 边注回到相关段落之后；目录作者与页码移到可读的第二行。
- 主视觉减少卫星物件数量，保留叙事关键对象；不能只缩小所有图层。
- 代码/宽表单独横向滚动，整个文档不横向溢出。
- 横屏或软键盘变化后重新检查工具栏，不让它占掉大半阅读高度。
- 手机可默认静态或低复杂度动态，但不要改变文字、数据和文章顺序。

## 8. 打印与 PDF

print 样式展示所有应输出页面，包括屏幕上 hidden 的页面；移除工具栏、浮层、舞台、阴影和封面旋转。背景回到浅纸色，正文与线条在关闭背景打印时仍有对比。

动态图使用有意义的确定静帧；不要在任意帧截图后不检查构图。Canvas 可能在打印中失效，使用同主题 SVG/图片静帧并检查显示规则。静帧也需要图注和必要文字。

标题避免孤悬，短图和图注尽量同页；长表、代码和列表允许跨页。纸张尺寸/边距以实际交付要求确定，常见 A4 只是默认起点，不等于专业印刷出血规格。正式印刷另处理出血、安全边界、颜色流程和字体授权。

导出前等待字体与图片就绪；导出后逐页检查页数、字体、断行、空白页、裁切和可选文本。有打印按钮不等于已完成 PDF。PDF 不携带网页动画，交付说明中写清。

## 9. 公开、会员和派生版

发布操作按用户授权范围进行。公开封面、内部刊物、会员正文、分享卡片、PDF 分别判断访问权限。不能把受限文章预先打进公开 JS、静态索引、截图合集或下载包。

生产 SSR 只返回用户有权获得的正文；涉及权益的 HTML 不进入共享缓存。目录可公开允许的元数据，但不得通过摘要字段夹带全部文章。生成公开样刊使用原创或明确可公开内容。

## 10. 状态和失败矩阵

至少考虑：首访、深链接、最后一页、返回、横竖屏变化、字体回退、慢图/缺图、无脚本、减少动态、快速连续翻页、打印、长标题、空作者、超长表格、非 ASCII 锚点。

功能未实现时在交付中明确说明，不能用设计文档的要求冒充样刊已经具备全部能力。示例只演示部分机制，生产作品必须按实际范围验收。
