# 纸书交互：封面、书脊、纸叶与点击区域

BaiLian 的默认体验是直接翻阅一本书。没有独立的封面进入按钮，不显示动态暂停、连续阅读、主题或阅读模式切换按钮。目录保留为安静的辅助入口，上一页/下一页贴着纸张两侧，而不是排在书本底部。

这是用户明确指定的产品行为，优先于旧版本关于默认工具栏的建议。其他任务有不同明确要求时再适配，不能把此界面变成无条件适用于所有读者的合规结论。

## 1. 封面就是入口

封面作为一个完整的可点击表面：鼠标短点击或触摸轻点进入刊首语；键盘焦点到封面时，Enter/Space 打开。用可访问名称说明动作，但不要在封面再加一个“开始阅读”按钮。

封面内若有真正的链接/控件，它们的事件不触发整页进入。封面提示来自光影、纸角和悬停，而不是一层遮住文字与图像的透明按钮。无脚本时按自然顺序展示全文，不保留假装可操作的封面角色。

## 2. 封面的两种运动要分开

**表面反馈**：鼠标位于封面时，封面在约 ±1.5–2° 范围内轻微倾斜并抬升约 3–4px；阴影稍加深。移出时回到原位，反馈只在 fine pointer/hover 设备启用。标题不会在版面内相对图像乱动。触摸设备不重播 hover。

**画面内部**：人物保持稳定，书本纸页绕实际书脊逐张翻动；咖啡杯可轻微浮动，蒸汽独立上升和淡化。内部动画不依赖鼠标，不是整幅摄影图一起漂移。背景色块默认稳定。

旋转与位移定义在不同层：封面负责空间反馈，人物图负责定位，书叶负责自身翻转。不要复用一个 transform 同时完成三种责任。

鼠标坐标以不参与旋转的书本容器测量，比例限制在 0–1。不能每次都从已经倾斜的封面包围盒反推位置，否则页面自身的运动会改变下一次测量，造成边缘抖动。移出时清理角度，键盘焦点提供相同程度的空间反馈。

## 2.1 首屏比例与封面排版

同时检查 1280×720 这类普通笔记本屏幕和高分辨率屏幕。首屏应看到刊名、主题、人物正在读的书及底部信息；不能只看见人脸，让书本落在屏幕之外。大气来自主次比例和完整构图，不是无条件增大像素尺寸。

桌面封面宽度取单页可用宽、最大纸宽与可用屏幕高度对应宽度的较小值。样刊以 `(视口高度 − 112px) × 0.66` 为起点，同时设 360px 下限；短窗口宁可自然滚动，也不把必要文字压到难辨认。普通笔记本中的小信息至少 11px，标题至少 32px。正式刊物有更多封面文字时重新计算，不照抄系数。

字体、内边距和图文间距随封面容器调整，并分别设置字号下限；不用一个 transform:scale 缩小整张页面。正文页仍保持正常行宽与字号。轻薄的两三层纸边可以提示厚度，不能变成厚重卡片边框。

## 3. 读书场景的分层

摄影主体是人物、桌面与书本的完整透明切片。书本落在画面中央偏下，双手避开纸页主要区域；原图中静止的书本始终保留，作为 reduced-motion 和无脚本后备。

在原图书脊上叠加少量纸叶，锚点要与照片的书脊一致。优先使用实际纸页的纹理片段作为图层表面，避免纯白矩形盖在暖色摄影纸页上。纹理片段可以用同一图像的 CSS 背景定位呈现，原文件保持完整。

每张纸叶有自己的时间相位，先轻抬、再跨过书脊、再落下或隐入书页。不要像扇叶一样始终均匀旋转，也不要让三张纸同一时刻穿过彼此。静止时不暴露重复的白色覆盖片。

咖啡杯是独立透明图，蒸汽为单独可编辑路径。对象的位置、阴影与人物桌面相容；蒸汽不能从没有杯子的空白处出现。

## 4. 打开封面要看见翻纸

封面点击后围绕书脊翻向左侧，揭示刊首语跨页。封面适屏后可能小于内页，打开时要同时衔接尺寸和书本重心；不能在最后一帧突然变宽、压扁或改变文字换行。

纸叶有正面和背面：正面为离开的页，背面为到达跨页的对应页。背面预先旋转 180°，整体翻转后文字仍正向；禁止镜像的正文。书脊侧阴影随角度加强再减弱，不能仅将整本书淡出再淡入。

建议 400–500ms 内完成。用户再次翻页时可以收束上一次过渡并开始新的过渡，不锁住输入；每次结束移除临时纸叶、阴影和动画实例。

## 5. 内页的点击方向

桌面：左页短点击后退，右页短点击前进。小屏：单页左侧约三分之一返回，其余区域前进。两侧箭头提供明确方向；首尾不能越界，也不循环跳转。

箭头属于书本，不属于整页工具栏：位于纸面之外或纸边留白区，图形轻，点击区域不小于 44px。小屏允许触摸区域覆盖一部分安全边距，但不能盖住正文。长页中，箭头在书本范围内保持可达。

点击图片也可以翻页，除非这张图明确有放大/交互能力；有专用动作的元素优先执行自己的动作。

## 6. 不误伤阅读

- 链接、目录条目、按钮、表单、交互图、可编辑区域不触发纸面翻页。
- 记录 pointerdown 与点击位置，移动超过轻点阈值时当作拖动/滚动，不翻页。
- 有非折叠文本选择时不翻页；清除已有选区也不应突然翻页。
- 多击选择文字与普通短点击要分别处理；文字区域的单击可延后约 250ms，在第二次按下或形成选区时取消。封面、图片、纸面留白和箭头立即响应。实际测试鼠标拖选和触摸滚读，延迟值不能保证所有系统的自定义多击间隔。
- 普通垂直滚轮不翻页，不拦截浏览器缩放与返回。
- 方向键只在阅读上下文处理；弹层和控件内保留其原行为。

正文是实际文本；纸面点击是增强行为，不能用截图或覆盖层换取它。

## 7. 双面纸叶的实现边界

短刊可用 CSS 3D + Web Animations API，无额外翻书依赖。真实 DOM 提供阅读语义，临时的纸叶副本仅负责约半秒的过渡。副本必须 aria-hidden/inert，移除重复 id；Canvas 需复制当前像素，否则翻过去时会出现空图。

离开的半页保留当前视觉，背面使用到达页的视觉；固定的一半保持连续。副本中的内部动效冻结到当前姿态，避免既转纸又重新开始动画。过渡完成立即移除副本，不让它进入打印或成为额外可聚焦页面。

封面与内页尺寸不同时，正面按离开页的尺寸排版，背面按到达页的真实尺寸排版；背面先做逆向尺寸补偿，纸叶整体在终点恢复目标尺寸。保持左右书脊轴的坐标一致，终点应与 live DOM 的四角重合。使用容器单位的字级必须在副本的纸面容器中计算，不能误以整个浏览器宽度计算。窗口在过渡中改变大小时立即移除旧几何的纸叶。

快速操作、浏览器返回、目录跳转和响应式断点变化共用一个导航模型，不能建立两套页码状态。反向翻回封面同样有收拢感。

导航模型保存的是读者选中的实际页面 id；左页索引只是从它推导的桌面布局值。例如读者跳到第 04 页，桌面显示 03—04，切到手机仍须显示 04，而不是把 03 当作读者目标。浏览器返回无 hash 的初始地址应恢复封面；同一跨页内跳到另一篇也要更新目标 id。

## 8. 自动停止与降级

没有可见暂停按钮仍不意味着后台一直运行。离屏、后台、目录完全覆盖、打印、页面卸载时停住对应场景；重新可见只恢复一条绘制循环。

系统减少动态时：封面不倾斜，书中纸叶不翻动，杯子和蒸汽静止，界面直接切换到目标页。真实照片中的书本保留完整静帧。无脚本时显示顺序正文和摄影图，不出现失效的模式/翻页控件。

## 9. 验收清单

封面没有独立进入按钮；全页点击、Enter/Space 均可打开；悬停有轻微反馈且移出复位；内部书叶和蒸汽各自变化；打开和正反翻页有纸叶过渡；文字不镜像；两侧箭头位置正确；纸面点击、拖选、链接和滚动不冲突；快速连续翻页不遗留副本；移动端无横向溢出；减少动态与打印路径保持完整。
