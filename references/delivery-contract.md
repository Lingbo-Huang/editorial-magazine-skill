# 便携交付：文件完整、字体可靠、输出可核验

在要求离线、单文件、分享包或静态导出时读取本文件。默认沿用独立 HTML/CSS/JS 和本地媒体；不为一句“单文件”牺牲可编辑源。

## 1. 先区分三种交付

| 形式 | 实际包含 | 适合 | 需要说明 |
|---|---|---|---|
| 本地目录 / ZIP | HTML、CSS、JS、图层、静帧、必要字体 | 可编辑杂志与分层动效 | 解压后保持相对路径；远端资源另记 |
| 自包含 HTML | 必要 CSS/JS 和资产内嵌 | 小体积、单文件传递 | 外链图片/字体存在就不叫完全自包含；内嵌会增加文件体积 |
| 在线页面 | 页面与托管资源、可能的服务接口 | 需要实时数据或权限的刊物 | 联网和账户依赖；不能承诺下载 HTML 即离线可用 |

HTML 幻灯片不是可编辑 PPTX，静态截图不是动态网页；文件名或技能名称不能作为格式能力的证据。仅在用户要求对应格式时另行制作并核对实际文件。PDF、分享卡片和公众号版各自记录状态。

## 2. 资产与字体的实际依赖

先列运行必需资源，再区分装饰增强和点击后才访问的外链。检查 HTML 的 src/srcset/stylesheet，CSS 的 url()/@import/@font-face，以及 JS 中的 import、fetch、Worker、媒体地址。仅搜索 HTML 里的 http 字样不能证明离线完整。

- 系统字体：无需下载，但跨平台字形不同；用回退字体试排最长标题与正文。
- 本地字体：确认可以分发，记录实际字重和中文覆盖；有缺字时检查回退是否改变行高。子集化须包含真实内容，内容更新时重新生成。
- 在线字体：标明联网增强；断网后仍能读不等于字体和视觉完全相同。
- 图标：优先已有本地或 inline SVG；不能为了几个箭头引入在线图标脚本。装饰图标与真实文字分开。
- 相对路径：包含中文、空格、查询版本号与大小写差异时检查实际解析。资源不能指向制作者电脑的绝对路径。

资产清单记录用途、原始源、当前导出文件、尺寸、裁切焦点、文字等价信息及发布范围。一个场景包含多个图层时，同时记录其共用坐标系和静帧；单个透明 PNG 不代表整个场景已打包。

## 3. 从工作模板生成成稿

复制适合的已有骨架后，先替换文档 title、刊名、主标题、目录和元数据，再按页面地图修改正文。检查模板中的伪数据、示例作者、失效链接和空图片。工作模板允许字段提示；最终读者页面不得残留未填写内容。

不要只搜索一种占位符。核对 `[必填]`、待填提示、旧主题标题、示例期号、空 href、空 src 与不属于本期的署名。数字即使没有占位标记，也要逐项核对来源。保留模板不是删除真实数据的理由。

## 4. 正确的截图就绪条件

等到必要字体完成加载或明确回退，图片完成解码且 naturalWidth 非零，页面进入目标状态，再检查布局。任意等 1–2 秒不能替代这些条件。懒加载图片需要先实际进入其页面；加载失败记录并修复，不把空白块作为通过截图。

普通页面取稳定帧；动态图至少检查初始、极限与静止姿态，并观察完整周期。书页过渡另检查中间角度、正反面和最终目标页。静态截图无法证明独立运动或后台停绘，需要实际动作记录。

字体替换后重新检查换行和页脚位置。不要在字体未到时截图，再把最终字体名字写到交付说明中当作已经验证。

## 5. 离线声明的验证范围

需要承诺离线时，在关闭浏览器缓存或使用干净浏览器上下文的条件下禁用网络，重新打开产物。热缓存断网后还能显示，不能证明包内资产完整。

按实际承诺测试：

1. 直接打开本地 HTML，检查封面、目录、正文、图层和静帧；若依赖本地 HTTP 服务，明确运行方式，不称双击即用。
2. 经本地服务打开时再次禁用外网，检查资源、字体回退、深链接与翻页。
3. 进入后续页面，确认懒加载图片也能从包内取得；对照资源请求和控制台记录定位缺失。
4. 原文外链允许需要网络，但必须与本刊必需内容区分；离线不需要假装远端文章仍可访问。

记录实际通过的启动方式、浏览器、网络/缓存条件与失败项。没有完成此测试，只能写“代码检查未见外部运行依赖”，不能写“离线实测通过”。

## 6. 输出清单与来源映射

交付目录包含用户要求的实际文件、可编辑源、必要媒体和简短运行说明。保留文章与页面 id 映射，避免重新分页后素材按旧页号命名而失去对应关系。

PDF 导出与打印规则见 [阅读器](reader-contract.md#8-打印与-pdf)。只交付 HTML 时无需额外制造 PDF 或视频；要求这些输出时，必须存在对应文件并检查正文、静帧与字体。

发布范围和验收记录见 [质量门槛](quality-gates.md)。向远端上传后核对提交与文件，不把本地打包称为已经发布。不能从外部模板里的流程说明推导出付款、上传或安装授权。
