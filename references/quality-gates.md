# 艺术审校与验收门槛

## 1. 先验硬性条件

任一失败都要修复，不能用漂亮封面抵分：

- 品牌、内容、署名、来源或技术事实错误。
- 原文模式下漏段落、漏条件，正文被遮挡/裁切。
- 手机双页缩成不可读的小字，或整页横向溢出。
- 离屏/后台动画仍持续运行，或系统减少动态被忽略；BaiLian 不要求可见暂停按钮。
- 图像/字体未就绪、占位文字或模板字段进入成稿。
- 内部对象本应独立，却只有整张图整体移动。
- 公开产物带入受限资料、账号信息、私有服务地址或没有授权的素材。
- 宣称已导出/测试/发布，实际没有对应产物或证据。

## 2. 艺术质量评审表

每项 0–4 分：0 缺失；1 仅搭架子；2 可用但普通；3 成熟一致；4 表达鲜明且细节充分。评分用于定位修改，不是客观认证。正式交付建议各维度至少 3 分，不用总分掩盖短板。

| 维度 | 3–4 分应看到什么 | 低分时先修什么 |
|---|---|---|
| 编辑命题 | 封面、目录、正文回应同一问题 | 重新选题与排序，别先加装饰 |
| 整期身份 | 字体、纸面、网格、细线贯穿全期 | 固定 token 与重复元素 |
| 页面节奏 | 开篇/解释/证据/收尾各有责任 | 改页面家族和密度，不只换色 |
| 字体排版 | 中文断句自然，层级稳定，行宽舒适 | 字级、行距、语义分行 |
| 构图与留白 | 一个主焦点，空白有用途，跨页平衡 | 主次比例、对齐与光学重量 |
| 视觉资产 | 裁切精确，光向/材料统一，细节真实 | 替换劣质资产，重做边缘 |
| 动态编舞 | 内部对象各有节奏，静帧也成立 | 锚点、幅度、相位、运动目的 |
| 阅读体验 | 手机、目录、焦点、纸面翻页都自然 | 去掉阻碍阅读的表现效果 |

不要在没有实际视觉检查时填满分。不能把“符合 CSS 规范”当成艺术质量已经达标。

## 3. 三轮视觉审校

### 整期缩略图

将页面按阅读顺序排列成接触表。标出主焦点位置、文字密度、主色、动图位置。检查三组相邻跨页是否机械重复；连续高密度/低密度是否使阅读失衡；封面与内页是否像两个项目。

### 实际阅读尺寸

在桌面和窄屏看完整的正文页，不只截首屏。阅读标题、导语、一段正文和图注，检查层级是否需要“努力找”。滚到页面底部，检查页脚是否挤压最后一段。

封面另检查约 1280×720 的首屏：人物正在操作的书或工具不能被裁到屏幕之外。较短窗口允许滚动，但不应靠把必要字级无限缩小来达成适屏。

### 放大细节

检查头发/叶片透明边缘、纸边锯齿、阴影方向、线条端点、中文标点、字重、图注间距、页码对齐。寻找尴尬相切、接近但不对齐的边、无意义小色块。能删掉且更清楚的装饰直接删除。

## 4. 动态审校

分别记录运行与自动停止状态；多个内部层确实发生不同变化。离屏、后台或减少动态后的图层状态应停止推进。检查至少一个完整周期与极限姿态，不能只看一秒。

快速切页、离开并重新进入场景，确认没有加速和多循环；检查离屏/后台/打印/减少动态。再回到实际读文：如果眼睛不断追逐角落，减弱动态。动画技术正确但干扰阅读，也不通过。

## 5. 可读与可操作

至少测试代表性桌面宽度与约 390px 窄屏，并检查文字放大。目录跳转、首末页、返回、Esc、Tab、方向键、纸面点击都能工作；无脚本仍有正文和静帧。交互元素的可达性不能只通过鼠标测试推断。

目录跳到桌面右页后缩窄窗口，确认目标页保留；在同一跨页内更换目标后重复检查。返回无 hash 的初始地址、翻页过程中 resize、封面悬停移入/移出、真实拖选与清除选区分别验证。

正文/图注/链接对比度计算到实际底色，尤其注意半透明工具栏和图片上的字。低对比装饰允许存在，但不能承载唯一必要信息。

## 6. 内容与技术审校

原文模式逐段核对覆盖；精选模式检查摘要没有改变结论与限制。图表的单位、轴、图例、箭头和数字逐项核对。原创技术视觉注明示意，不能和实验结果混淆。

真实资源加载后检查布局；重复进入场景不增加活动计时器；没有无用的全量媒体预加载。生产长刊测量真实内存与帧耗时，不借用七页示例的表现。

## 7. 验证记录格式

每条记录包含：范围、环境/视口、操作、观察结果、证据位置、状态。状态用“实际通过 / 代码检查 / 未验 / 失败”，不得将后两者写成通过。没有图片或视频时也可记录真实 DOM/帧数据，但视觉质量仍需要人眼查看。

示例：

| 检查 | 方法 | 合格证据 |
|---|---|---|
| 图层独立运动 | 两个时刻读三个对象的变换 | 三者不是相同父级变换 |
| 自动停止 | 离屏或系统减少动态后检查 | 内部图层与绘制循环停止 |
| 手机阅读 | 390px 完整滚读 | 无整页溢出、正文未裁切 |
| PDF | 导出并逐页查看 | 字体/分页/静帧可见 |

## 8. 发布前检查

确定上传的文件清单，仅包含本次技能、原创示例和必要资源；不要整仓推送工作区。检查路径、日志、链接中无个人机器路径、私有站点地址、令牌或内部素材。README 说明实际功能、使用方式、示例边界与许可。

远端发布后核对仓库可见性、分支和提交，读取远端 SKILL.md 确认可访问；只有本地 commit 不算上传完成。没有实际部署的预览不能给出伪造在线地址。

## 9. 四个典型任务的前向检查

1. **原文不许删**：提供很长的文章时，应增加续页或允许单页自然增长并保留内容，而不是为固定十页做摘要。
2. **人物物件都要动**：应先取得独立图层、定义遮挡和锚点；只有一张平面图时说明重构需求，不能宣称无损拆分。
3. **技术主题要华丽**：区分抽象主视觉与真实机制图；视觉可以有张力，数据与箭头必须保持准确。
4. **只给一篇短文**：应做适度的短专题，不生成虚构作者、伪造证据或几十页空泛引语来充数。

用这些案例检查技能是否引导正确行为。仅在实际执行了一个任务时记录为已完成的前向测试，不能把阅读案例称为独立评测。
