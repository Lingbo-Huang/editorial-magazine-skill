# 整期组织与页面节奏

## 1. 先处理材料，再决定页数

列出所有候选内容：标题、作者、日期、来源、核心问题、结论、证据、图片、使用范围、是否可删改。把“需要保留的论证”和“可以作为延伸阅读的内容”分开。原文排版模式不能擅自把后者删掉，只能移到续页。

选题判断四件事：是否服务中心问题；读者是否得到新理解；有无足够依据；是否与其他文章重复。重复内容合并或改变承担的任务。不要因为有一张好看的图就把无关文章放进主专题。

明确每篇文章在本期中的角色：提出问题、解释机制、提供证据、给出反例、指导实践、完成回顾。正文标题尽可能表达问题或判断，而不是全部叫“背景”“介绍”“总结”。

## 2. 从目录到阅读弧线

推荐的知识刊物路径是：**入口 → 编辑视角 → 阅读地图 → 主专题 → 解释/证据 → 实践/反例 → 收束与来源**。不是每期都需要八个独立章节，也不是必须按这一顺序机械排列；缺少某一环节时要能说明原因。

封面只推一个主专题，可加不超过两到三个次级入口。目录可以列多个主题，但短摘要必须解释区别。主专题占据最大的编辑和视觉预算；不能所有文章都使用同样的大标题和满版图。

## 3. 页与跨页的责任

页面是屏幕表现单位，文章是内容单位。稳定 id 绑定文章/场景，页码是排版结果。桌面一组跨页可以包含两篇短内容，也可以属于一篇长文章；手机不能因此颠倒段落顺序。

| 页面家族 | 编辑任务 | 视觉密度 | 适宜动态 |
|---|---|---|---|
| 封面 | 建立身份与主问题 | 一强焦点、少文字 | 可选一处轻微运动 |
| 刊首语 | 交代编选理由 | 中低密度 | 通常静止 |
| 目录 | 帮助选择 | 结构化中密度 | 只保留交互反馈 |
| 专题开篇 | 提出命题 | 大字、大图、少正文 | 可容纳主要场景 |
| 正文续页 | 解释与推进 | 稳定中高密度 | 少量与理解有关的演示 |
| 证据页 | 比较、图表、案例 | 信息密度高 | 真实数据/步骤变化 |
| 呼吸页 | 让读者停顿 | 一句有信息的文字或一幅图 | 克制、可暂停 |
| 实践页 | 提供具体行动 | 顺序清楚 | 可操作演示，不增加噪声 |
| 收尾/来源 | 回顾与继续 | 中低密度 | 通常静止 |

“呼吸页”不能用空泛金句充数；可以是一个真实反例、一张有说明的照片或一个值得继续思考的问题。

选好页面责任后，用 [八类页面配方](layout-recipes.md) 确定对齐线、图文比例、分组与手机顺序。页面地图同时记录配方 id、内容密度、焦点位置与强调色角色；这些字段帮助检查整期，而不是自动决定实际页数。

## 4. 跨页的四种关系

**论题—主视觉**：左页标题/导语，右页大图。适合专题开篇。两页共同构图，手机顺序为标题、导语、图、图注。左页不要追加完整长文压缩标题。

**正文—证据**：左页论证，右页图表/机制/案例。图注说明它支持哪一句判断；必要的解释不能只藏在正文另一端。图表小屏放到对应段落之后。

**连续正文**：两页共同推进一篇文章。相同字级、行宽、基线；跨页时在自然段/小节边界断开，避免孤立标题和只剩一行的段落。

**对照—对照**：两个方案、两个状态或正反案例。保持可比较的尺度、字段和视觉权重；不同颜色也要用文字标签说明。不能因为一方视觉更酷而人为暗示结论。

## 5. 小型专题刊示例地图

下表只是节奏示例，实际页数由内容决定。来源字段必须填写实际文件/资料，不可把示例选题当成已完成正文。

| 顺序 | 页面任务 | 视觉关系 | 读者带走什么 |
|---|---|---|---|
| 封面 | 提出“从收藏到实践” | 大标题＋单一物件主视觉 | 本期主题 |
| 1–2 | 刊首与目录 | 左文右目录 | 为什么读、从哪里进入 |
| 3–4 | 主专题开篇与第一段解释 | 分层拼贴＋安静正文 | 收藏与理解的区别 |
| 5–6 | 机制与反例 | 可编辑流程＋真实案例 | 如何识别理解缺口 |
| 7–8 | 实践任务与记录 | 步骤、预期、观察区 | 可以开始的行动 |
| 9–10 | 复盘与来源 | 简洁收束、出处映射 | 下一次实践的起点 |

不用每两页都放一幅动态大图。一个短专题中，两处经过设计的动态视觉通常比十处默认循环更有效；数量由内容决定，不设硬性配额。

## 6. 翻页节奏与内容密度

把全部页面做成缩略图接触表。看连续三组跨页：是否都有相同位置的大标题和相同尺寸的图片；是否连续高密度导致没有停顿；是否连续低密度让内容显得稀薄。

可以采用“强开篇 → 稳定解释 → 强证据 → 稍慢的回顾”的变化。重复的是身份与网格，变化的是焦点位置、图文比例、密度和页面责任。不要把每页换字体、换底色当成节奏。

不用演讲时长估算阅读页数，不规定“八页必须一深一浅”或“每三至四页必插开篇”。连续正文允许同底色与同版心。深色开篇、大图和数字页都应有编辑理由；没有新内容时，合并页面比换底色更有效。

每页有主焦点和次焦点；对高密度图表页，主焦点可以是图表的结论，而不是最大字号的装饰英文。页脚和来源链接不能成为第三个高强度焦点。

## 7. 文章内部的编辑

导语补充标题未说完的“为什么”，不把标题换个说法复述。第一段尽快进入具体问题；背景只保留理解后文所必需的部分。转场句解释为什么从 A 进入 B，不把不同文章来源硬拼起来。

每个技术判断保留前提、适用范围和反例。将“观察到的结果”和“解释原因”分开。读者任务包含输入、动作和检查依据，不只写“深入思考”。引语必须有真实出处，不能为版式生成名人金句。

强调句来自论证的支点：一页通常一到两个足够。过多加粗时先减少强调，再调整正文。旁注是补充，不承载唯一的重要定义；补充复杂到需要多个段落时应进入正文或独立框。

## 8. 长文章与分页

先按语义拆节，再在章节内部排版。标题不能孤悬页尾；短图与图注尽量同页，长表/长代码允许合理跨页。不要对所有内容设置禁止分页，也不要强设固定高度后隐藏溢出。

对每个续页保留文章标识或简短 running head，让读者知道仍在同一篇。必要时使用“接上页”提示，但不制造大量重复正文。目录页码由最终排版更新，不能长期手写维护两套序号。

## 9. 内容完整与派生版

原文、精选刊、封面卡片、公众号版和 PDF 是不同产物，建立从源到派生的映射。原文更新后标记受影响的页面，而不是每个版本各改各的。

精选刊提供的原文入口只指向用户允许的可访问内容。会员正文不能因为导出杂志、预览图、静态 JSON 或 PDF 而泄露。公开封面不意味着整期正文可以公开。

## 10. 编辑验收

只读目录能说明本期问题；每篇有不同责任；封面承诺在正文中兑现；段落之间有论证关系；没有为了排版遗漏限定条件；来源/作者真实可追溯；收尾提供可执行的下一步而非重复开头。
