# dandan-learn 接入边界

品牌规则：使用用户明确指定的 **BaiLian**，保留大小写；以“杂志”“精选刊”“专题刊”描述形态，不添加固定出版周期。

建议定位：教程之外新增精选刊/专题刊。课程保持系统学习路径，刊物按本期问题组织已有文章与实践，不用杂志取代所有教程。

本次技能与样例不是线上栏目实施。用户要求接入时，先检查当时的 AGENTS.md、config/site.ts、Content 配置和已有组件，不把历史 track 数量写死。

| 层 | 适配方式 |
|---|---|
| 内容 | issue 元数据记录期号、主题、稳定文章 id/路径、顺序、摘要和权限；正文继续引用既有来源 |
| 样式 | 复用 main.css / book.css / site.css 中的 `--dd-*` token；新杂志变量集中定义，组件使用 `.dd-*` |
| 阅读 | Vue 组件管理自动跨页/单页与纸叶翻转；封面整页进入，边缘箭头和纸面点击翻页；DOM 文字保留，媒体客户端挂载后运行 |
| 动画 | 3–12 个图层优先 CSS/SVG，点阵优先 Canvas；已有依赖能解决时再用 GSAP，不默认新增 WebGL |
| 会员 | 正文继续经 BFF 权益检查；不得把会员正文/全库/会员插图打包进 public、公开 PDF 或静态 HTML |
| 访问 | 公开样刊仅使用已确认可公开内容；含权益的刊物沿用 SSR private/no-store |
| 来源 | 摘编对应原文、图注与资产记录保留；生成包的内容范围与访问范围分别确认 |

动态内容的特例：2026-11-13 用户明确要求元素分别持续运动，内容插画循环可超过原 UI 500ms 上限；按钮、目录、翻页仍遵循原时长约束。用户随后明确取消可见暂停与阅读模式控件；保留离屏/后台自动停止、reduced-motion 与静帧。这是本任务的局部调整，不改写全站动效基线。
