# 视觉资产：从艺术命题到可用图层

## 1. 先决定图像的任务

每幅图先写一句“它帮助读者理解或感受到什么”。分清摄影纪实、情绪主视觉、关系图、数据图、步骤图。不能用好看的抽象图替代必要机制图，也不能把所有页面都画成流程图。

素材清单至少包含：id、用途、来源/作者、允许的使用范围、原始尺寸、透明与否、焦点、安全裁切区、色彩处理、所属场景、alt、静帧与可编辑源文件。未知授权不写成已获授权；没有素材时优先重新创作或换表达方式。

## 2. 摄影拼贴的制作顺序

1. 画低细节静止构图：主组、卫星物件、文字安全区、圆形/纸片背衬。先用实心轮廓检查重量，不先挑照片。
2. 明确镜头与光线：主体和物件采用相容的视角、焦距感和光向。不能把俯拍碗、正侧面人物、极广角鞋子混成没有空间逻辑的世界。
3. 取得或创作分层资产：主组、道具、装饰形体、阴影分别可控。没有必要时不要把人物身体拆成不自然的部件。
4. 完成抠图、去白边污染、局部着色和颗粒统一；保留原始文件，不只保留压缩成品。
5. 在真实版面中检查图文关系，调整裁切；再设计对象的运动极限。
6. 导出透明图层与一张合成静帧；在浅底、深底、手机尺寸和打印尺寸分别检查。

只有一张平面图时，隐藏区域没有真实像素。要让原先被挡住的物件移动，必须取得原始分层文件或重新构建；不能承诺从截图无损还原全部素材。

## 3. 统一照片的材料语言

灰度转换后保留不同材质的层次：头发不能糊成黑块，毛衣纹理不能过度锐化，白瓷不能与纸边完全融为一体。先统一黑位、曝光和局部对比，再考虑颗粒。

选择性着色通常只覆盖与主题有关的少数区域：一本书、一台电脑、鞋带、一个日期格。颜色属于物件材质，需要保留光影；不要把蓝色纯色块不透明地盖到照片上。高彩度在多个区域出现时，面积和亮度应形成主次。

纸张暖色与照片灰度之间可以有轻微色温差，但不能一张偏紫、一张偏绿。全期摄影素材保持相同颗粒尺度；不要给已粗糙的图再次叠高强度噪点。

## 4. 纸边、撕口、接触阴影

纸边跟随主体轮廓，有少量不规则宽度；不规则不是每隔固定距离出现同样锯齿。最终 600px 宽场景中，可从约 2–6px 可见纸边试起；主组略宽、细物件略窄。以上只是制作起点，不能为纸边牺牲真实细节。

阴影拆为两种：贴近物件的窄接触阴影，以及非常轻的纸片离地阴影。光向统一，偏移小，边缘柔；“浮起来”的物件可让影子变淡、变小或稍偏移。阴影默认是独立层，不直接烘焙在有色背景里。

在透明棋盘和最终纸面上检查边缘，重点看头发、眼镜、细带、植物叶片和杯柄。半透明区域不应出现白色光圈或黑色脏边。对象运动到最远处时也不能露出原照片矩形边界。

## 5. 图层清单示例

| 层 | 职责 | 应否独立 | 静态约束 |
|---|---|---|---|
| paper | 背景触感 | 独立静止 | 不移动、不影响正文 |
| warm-disc | 聚焦主体 | 独立静止或极轻变化 | 不侵入标题安全区 |
| subject-group | 人物/桌面/主要工具 | 默认完整主组 | 表情与主体关系不拆散 |
| prop-a / prop-b | 补足叙事 | 分别独立 | 尺寸受叙事重量控制 |
| calendar | 时间提示 | 独立 | 日期不能被动画变成误导信息 |
| plant / textile | 触感和边缘平衡 | 依构图需要 | 边缘保持自然 |
| shadows | 接触/层次 | 随对应对象 | 光向、幅度和距离相容 |
| symbols | 极少量抽象标记 | 可独立 | 不成为第三套图标语言 |

对象可以共享一个素材文件但需要真实可编辑的节点/遮罩。截图整图加 float keyframe 不满足分层要求。

## 6. 生图与编辑的任务说明

调用环境支持的 imagegen 工具生成或编辑视觉素材；不要用 Python 替代被要求的图像编辑。先检查参考图片，再编辑。要求透明背景时必须使用工具的透明背景参数；不要生成棋盘格假透明。

用于分层资产的说明应包含：对象、材质、视角、镜头距离、光向、阴影策略、色彩处理、裁切边缘、透明背景、输出安全边距和不包含文字。每个对象沿用同一艺术指导，而不是分别写十个互不相干的提示词。

**原创主组提示词配方**：

> 为一份学习主题的编辑杂志制作可抠出的摄影拼贴主组：一个自然工作的成年人物与桌面上的笔记本形成完整主体，三分之四视角，柔和侧向日光。保留真实布料、纸张和皮肤层次，主体采用细腻灰度，只有指定工具使用克制的钴蓝局部色。边缘留出干净裁切空间，不包含标题、文字、商标或多余装饰。主组本身构图完整，后续会叠放在暖白纸面与暖色圆形前。需要透明背景时生成真正透明输出；阴影另做。

这是一种可替换的任务配方，不要求每期都出现人物、电脑或钴蓝。用户已提供授权人物照片时，尊重其身份和编辑范围，不凭空替换成其他人。

**道具提示词配方**：

> 制作与主组相同镜头、光向、颗粒和灰度范围的单一道具；完整轮廓，三分之四角度，透明背景。保留真实材质，在与本期主题相关的小区域保留强调色。不要带场景背景、标题、标签或烘焙大阴影；四周留足后续纸边处理空间。

若生成工具不能稳定输出统一资产，减少道具数量或改用整组静图加少量真实独立层；明确报告可编辑范围，不假装所有像素都能分开动。

## 7. 技术生成视觉的造型

先确定二维剪影：弧带、羽状面、网格团或轨道。主体要有明显方向，留出标题侧的负空间。再确定近远层：前景点较清楚，远处点较淡；点的大小和透明度变化应连续，不能随机闪烁。

用曲面参数产生规律，再加入受控扰动。少量方块沿主形体边缘聚散，轨道线以较低对比围绕主体。数量、尺寸、边缘密度都服从一个中心，不填满所有空白。

技术装饰允许有美学隐喻，但旁边必须说明它是抽象视觉。真实图表使用真实坐标和数据；不要把装饰方块配上未经验证的“吞吐提升”数字。

## 8. 精确图解的资产

流程图、时序图、架构图保留节点/连线的可编辑源。先检查事实与箭头，再定颜色和动效。文字优先 HTML/SVG 可选文本，不把长标签生成进位图。使用图例区分类别，避免箭头交叉到无法判断起止。

演示状态的动图至少有“初始—变化—结果”三态；每态仍有可读标注。速度变化不要改变事实中的事件先后。用户暂停时应能理解当前是哪一步。

## 9. 文件、加载与导出

文件名使用稳定语义 id，避免 final-final-2。动态场景保存静帧、图层文件、场景参数和说明。SVG 检查外部脚本、字体依赖和可访问文本；透明照片按实际显示尺度输出，避免给手机发送无必要的超大图。

记录尺寸与宽高比，采用响应式图片或分尺寸资源；首屏主视觉优先加载，后续大图延迟。不要为了加载进度先隐藏整页正文。PDF 使用足够清晰的静帧，图中的必要文字仍有文本等价内容。

## 10. 素材验收

图文关系明确；关键对象无意外裁切；透明边缘无污染；光向和颗粒统一；选色不破坏材质；每个应独立运动的对象有独立层；极限姿态不碰文字；文件大小符合目标设备；来源/授权状态真实记录。
